# Taskora ✦

Taskora is a simple, colorful task manager designed to make everyday tasks feel more rewarding.

## Features

- Add tasks with an optional time
- Mark tasks as complete or reopen them
- Earn 25 XP for each completed task
- Level up every 100 XP
- Daily completion streak
- Progress ring and XP progress bar
- Beautiful colorful interface
- Light and dark mode
- Responsive desktop and mobile layout
- Local persistence with `localStorage`

## Run locally

This is a static web app. Open `index.html` in a browser or serve the folder with any static HTTP server.

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
